# BGE-M3 через OpenRouter: живая проверка паспортного контура

Дата: 31.08.2026  
Режим: защищённый локальный `v2_preview`; публичный `/chat`, Legacy и `canary=0` не менялись.  
HEAD: `cc863d0` (`qa/live-evaluation-and-fixes-2026-08-22`), рабочее дерево до начала уже содержало пользовательские и незакоммиченные изменения.

## Что изменено

`OPENROUTER_EMBEDDING_MODEL` теперь по умолчанию равен `baai/bge-m3`. Явная настройка окружения по-прежнему имеет приоритет: смены секретов, LLM-модели и публичных флагов нет.

Использован тот же существующий `passport_index.json`, а не второй паспортный индекс. Смена имени модели автоматически исключает векторы старой модели и пересобирает индекс. Для OpenRouter добавлены:

- консервативные пачки по 32 фрагмента;
- повтор только временно неуспешной пачки (`429`, `5xx`, сетевой сбой);
- запрет перезаписывать пригодный кэш пустым индексом при временной ошибке провайдера.

Это важно для доказательности: частичный набор векторов не используется и не сохраняется.

## Телеметрия: доказательство BGE-M3 на текущем коде

Для VT.5000: владелец `v2`; один embedding-запрос `baai/bge-m3`, 1 вектор × 1 024; `index_model=baai/bge-m3`, `index_has_vectors=true`; retrieval `hits`; verifier и `product_fact_evidence_gate` — `accepted`.

Для VRS.254.18.0: тот же индекс BGE-M3, predicate `installation_length_mm`, retrieval и verifier — `accepted`; результат прошёл V2 evidence-gate.

## Вывод

**BGE-M3 подключена корректно и реально используется паспортным контуром.** На двух разных документах и в разговорной цепочке retrieval, verifier и V2 evidence-gate дали доказанные ответы. Модель не ослабляет source/evidence-gate и не создаёт второй индекс.

Однако это не означает «все перефразирования и все карточки готовы». Проверка показала два нерешённых семантических разрыва: словесные числа для котлов и перенос уже подтверждённого контекста наружной канализации. Отдельно полезно расширить registry predicate `expansion_tank_volume_l` для `8216262000`; документ уже есть, но безопасный путь намеренно не использует неописанный predicate.

Решение по этому ограниченному этапу: **accept для BGE-M3 migration и passport retrieval; block для утверждения полного языкового покрытия и публичного rollout.**
