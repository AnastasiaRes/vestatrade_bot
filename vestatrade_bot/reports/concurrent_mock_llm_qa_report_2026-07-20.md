# Конкурентный QA с mock-LLM

Дата: 20 июля 2026 года.

Этот прогон проверяет сетевой/оркестраторный LLM-путь, guardrails и изоляцию сессий с управляемым grounded mock-ответом. Он **не является доказательством качества реальной модели Ollama**.

## Результат

- Запросов: **100**.
- Независимых сессий: **10**.
- Параллельных workers: **10**.
- Ошибок инвариантов: **0**.
- Межсессионных утечек: **0**.
- LLM transport succeeded: **20/20 ожидаемых contextual ходов**.
- LLM output accepted: **20/20**.
- Источник финального ответа: **80 deterministic / 20 response_llm**.
- Latency p50/p95/max: **0,080 / 0,318 / 0,452 с**.

Проверялись десять фаз для каждого пользователя: exact-SKU setup, характеристики, совет, ссылка, цена, наличие, описание, цена+наличие, осторожная рекомендация и итоговая карточка со ссылкой.

Во всех фазах каждый ответ сохранил собственный SKU; чужих карточек, чужих SKU в тексте и потери session_id не найдено.
